## 🎯 Objetivo do aplicativo

O Nutriva é um aplicativo desenvolvido com o objetivo de solucionar o problema relacionado à doação de leite materno no Brasil.

O aplicativo permite que o usuário se conecte com bancos e postos de coleta de leite materno, obtenha informações sobre como realizar a doação e tire dúvidas relacionadas ao processo de doação de leite materno.

# 📱 Principais Telas

## 🏠 1. Tela de Apresentação

![Tela de Apresentação](imgs\homeScreen.png)

### Descrição

A tela de apresentação é o primeiro contato do usuário com o projeto Nutriva. Por meio dela, o usuário pode conhecer melhor o projeto e compreender suas principais funcionalidades.

---

## 📍 2. Tela de Localização de Postos

![Tela de Localização](imgs\mapaScreen.png)

### Descrição

A tela de localização de postos permite que o usuário encontre um posto de coleta de leite materno mais próximo ao informar seu CEP.

---

## 📅 3. Tela de Agendamento

![Tela de Agendamento](imgs\AgendamentoScreen.png)

### Descrição

A tela de agendamento permite que o usuário realize um agendamento com o posto de coleta desejado e acomponhe o seu progresso, podendo marcar uma visita, realizar uma doação ou participar de um evento.

---

## ❓ 4. Tela de Dúvidas

![Tela de Dúvidas](imgs\faqScreen.png)

### Descrição

A tela de dúvidas foi desenvolvida para esclarecer dúvidas do usuário relacionadas à doação de leite materno e fornecer informações importantes sobre o processo de doação.

---

## 🍼 5. Tela da Jornada

![Tela da Jornada](imgs\JornadaScreen.png)

### Descrição

A tela da jornada foi desenvolvida para informar a usuária sobre todas as etapas do processo de doação de leite materno, desde a preparação até a entrega do leite no posto de coleta.

---

## 🔐 6. Tela de Acesso Restrito

![Tela de Acesso Restrito](imgs\LoginScreen.png)

### Descrição

A tela de acesso restrito permite que o usuário acesse sua conta de administrador e, posteriormente, tenha acesso ao dashboard com os dados relacionados ao projeto.

---

## 📊 7. Tela de Dashboard

![Tela de Dashboard](imgs\DashboardScreen.png)

### Descrição

A tela de dashboard permite que o usuário com acesso de administrador visualize dados relevantes relacionados ao projeto, facilitando o acompanhamento das informações e dos principais indicadores da aplicação.

cd Nutriva-sprint3
flutter run -d chrome
